# **혼자 공부하는 SQL**

## **개요**  
이 레포지토리는 **2026년 2월 15일**부터 **3월 26일**까지 **혼자 공부하는 SQL** 교재를 기반으로 MySQL 설치부터 기본 SQL 문법과 고급 문법, 그리고 SQL과 파이썬 연동을 학습한 내용을 정리한 것입니다.
또한 학습 결과로 **SQL 개발자(SQLD)** 자격증을 취득하였습니다.  

## **주요 특징**  
- MySQL 설치 및 설정
- 기본 SQL 문법 학습 (SELECT, INSERT, UPDATE, DELETE)
- 고급 SQL 문법 (조인, 인덱스, 스토어드 프로시저)
- SQL과 파이썬 연동 실습

## **기술 스택**  
- **SQL**
- **MySQL**
- **Python**
